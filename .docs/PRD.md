# 灵光

灵光是一个 AI 助手，它可以通过对话的方式创建一个闪应用，应用可以分享（有独立路由），闪应用使用 local storage 存储数据，没有数据库。

## 产品愿景

**让复杂，变简单** —— 用户只需用自然语言描述需求，即可快速生成可用的小应用。

## 核心功能

### 1. 对话式应用创建

用户通过自然语言描述需求（如"帮我写一个日程表应用"），AI 会：
- 理解用户意图，给予热情友好的回复
- 展示应用构建过程（思考卡片）
- 实时生成并预览应用

### 2. 闪应用

- 轻量级单页应用，嵌入在对话流中展示
- 支持全屏查看
- 使用 Local Storage 持久化数据
- 支持独立路由分享

### 3. 迭代优化

- 用户可以继续对话，提出修改建议
- 系统提供快捷建议按钮（如"任务完成来个庆祝动画"、"给任务加个优先级标"）
- 支持重新生成、分享、点赞/点踩反馈

## 组件设计

### 输入框组件

- 左侧：附件/插件按钮（带 + 号的机器人图标）
- 中间：文本输入区域
- 右侧（空闲状态）：语音按钮 + 相机按钮
- 右侧（输入状态）：发送按钮
- 右侧（生成中）：停止按钮

### 思考卡片

- 标题：任务名称（如"构建日程表应用框架"/"部署日程表应用"）
- 状态图标：加载中（旋转圆圈）/ 已完成（勾选）
- 内容：AI 的思考过程和步骤说明
- 可折叠展开

### 应用预览卡片

- 左上角：闪电图标 + "保存"按钮
- 标题区：应用名称 + 副标题
- 右上角：全屏按钮
- 中间：应用内容区（可交互）
- 右下角：收起/展开按钮

### 快捷建议

- 横向滚动列表
- 每个建议前带魔法棒图标
- 点击后自动发送对应消息

### 反馈操作栏

- 重新生成按钮
- 分享按钮
- 点赞按钮
- 点踩按钮

## 视觉设计

### 主题风格

- **整体风格**：深色主题，科技感与温暖感并存
- **背景**：深色底 + 蓝紫渐变光晕效果（模拟"灵光"意象）

### 配色方案

| 用途 | 颜色 |
|------|------|
| 背景色 | 深灰/近黑 `#1A1A1A` |
| 光晕效果 | 蓝紫渐变 |
| 主强调色 | 蓝色 `#007AFF` |
| 用户气泡 | 深灰 `#3A3A3C` |
| 应用卡片背景 | 白色 |
| 文字主色 | 白色 |
| 文字次要色 | 灰色 `#8E8E93` |

### 字体

- Slogan：较大字号，居中展示
- 正文：标准字号，易读性优先
- 卡片标题：中等字号，加粗

## 数据存储

### 对话数据

```typescript
interface Conversation {
  id: string
  title: string
  messages: Message[]
  createdAt: Date
  updatedAt: Date
}

interface Message {
  id: string
  role: 'user' | 'assistant'
  content: string
  app?: GeneratedApp  // 如果生成了应用
  timestamp: Date
}
```

### 闪应用数据

```typescript
interface GeneratedApp {
  id: string
  name: string
  description: string
  code: string  // 应用代码
  data: Record<string, any>  // 应用运行时数据
  conversationId: string
  createdAt: Date
}
```

### 存储方式

- 所有数据存储在浏览器 Local Storage
- Key 命名规范：`lingguang_{type}_{id}`

---

## 技术要点

1. **流式响应**：AI 回复采用流式输出，实时展示
2. **沙箱执行**：闪应用在安全沙箱中运行
3. **代码生成**：AI 生成的应用代码需要实时编译预览
4. **离线支持**：所有数据本地存储，支持离线访问历史记录
